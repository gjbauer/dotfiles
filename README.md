# Dotfiles - my Unix configuration

This current configuration is set to target Ubuntu ARM64, with branches for macOS, OpenBSD, FreeBSD and Arch Linux.

That being said, in order to make this configuration usable, one must install in addition to sway & zsh; waybar, fuzzel, konsole, swaylock-effects, ohmyzsh, and finally two font packages - noto-basic & noto-emoji. Be sure to follow the correct instructions to enable the graphics drivers for your platform, add your user to the video group, and enable seatd!!
